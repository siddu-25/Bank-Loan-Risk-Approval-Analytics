# 🏦 Bank Loan Risk & Approval Analytics

> A beginner-friendly Data Analytics project focused on analyzing bank loan applications, applicant credit profiles, and loan approval patterns using Python, SQL, and Microsoft Excel.

---

## 📌 Project Overview

This project analyzes a bank loan application dataset to understand loan approval patterns and identify factors associated with loan outcomes.

The project follows a complete data analytics workflow:

**Raw Data → Data Cleaning → Exploratory Data Analysis → SQL Analysis → Excel Dashboard → Business Insights**

The analysis focuses on loan status, CIBIL score categories, applicant characteristics, income, loan amount, and other available attributes.

---

## 🎯 Objectives

- Analyze overall loan application and approval patterns
- Understand the relationship between CIBIL score and loan status
- Categorize applicants based on CIBIL scores
- Explore loan status across education and employment categories
- Calculate important business KPIs
- Build an Excel dashboard for easier interpretation
- Generate actionable insights from the available loan data
